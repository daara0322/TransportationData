# 분석 설정과 정책 사실표

`probe_routes.json`은 초기 연결 실험용 목적표본이다. `authorization_matched_routes.json`은 1월 인가현황의 노선명과 운행기록을 대조해 만든 잠정 후보 ID 목록이며 공식 전체 노선 목록이 아니다.

`lowfloor_exceptions_2026.csv`는 [서울시 저상버스 예외승인 현황](https://news.seoul.go.kr/traffic/archives/513625)의 2026년 게시용 표에서 노선·대수·제약 유형의 사실관계를 수기로 정리한 것이다. 원본 이미지는 `data/raw/seoul_lowfloor_exceptions_2026_03.png`에 보존하고 재배포하지 않는다. 여러 업체가 있는 노선은 대수를 합쳤으며 번호의 앞자리 0을 보존한다. 적용기간과 변경 여부는 추가 확인이 필요하다.

- `approved_buses`: 표의 해당 노선 운행대수 합. 25개 노선 합계는 235대다.
- `primary_constraint`: 교량 통과 여유, 급경사, 도로 폭, 충전·중형차 공급 조건의 사실을 분석용 영문 코드로 구분했다. 실제 운행 가능성을 판정하는 값이 아니다.
- `additional_charging_overlap_buses`: 표 하단 중복 표시의 충전 제약 대수. 0017번 9대, 5519번 6대, 8003번 1대이며 이미 본문 대수에 포함돼 있다. 전체 235대에 다시 더하지 않는다.

충전·중형차 공급 조건은 표에서 전기충전시설, 대체차량과 모델 공급 문제를 함께 설명한 항목이다. 현재 충전시설이 없거나 교체가 불가능하다고 단정하지 않는다. 예외 목록에 없다는 사실도 교체 가능성을 보장하지 않는다.

`gangbuk_building_scenarios.json`은 시설 C5044 한 곳의 본관·별관 주소 시나리오다. 본관은 한국장애인개발원 기관 안내로 주소를 대조했고 별관은 원본의 표기만 확인했다. 두 점은 실제 출입구 검수 완료가 아니며 기존 시설 수에 추가하지 않는다. API 응답·인증정보·원본 좌표는 이 설정에 없다.
