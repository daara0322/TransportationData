# AI 활용 기록

2026-10-18까지의 작업 기준이다. 제출 전에 실제 수행 내역과 공고 양식을 다시 대조한다.

생성형 AI는 연구계획 초안, 공개 데이터 검색과 명세 확인, 원자료 품질 점검 코드, 버스위치 API 수집 및 차량·노선 ID 연결 코드, 결과 문서 초안 작성에 사용했다. 실제 공개 파일과 API 응답으로 집계했으며, 모의 결과를 연구 성과로 사용하지 않았다. 예측모형을 학습하거나 AI 예측 정확도를 측정한 단계는 아니다.

검증 코드에서는 BOM 제거와 ID 보존, 거리값 구분, 중복 후보, API 오류·데이터 없음, 알 수 없는 저상 분류, 차량·노선 연결과 분류 충돌을 점검한다. 연료와 거리 단위가 확인되지 않은 상태에서 탄소감축량을 작성하지 않았다.

후속 작업에서는 공식 노선 마스터와 차량별운행노선정보의 ID 대조, 후보 명칭·유형 불일치 기록, 미분류 차량을 고려한 조건부 구성 범위 계산에 사용했다. 이 범위를 통계적 신뢰구간이나 실제 대기시간으로 해석하지 않는다.

정책 해석과 제출 문장은 팀이 원문 및 집계 결과와 대조하고 수정해야 한다. 사람이 검토하지 않은 문장을 검토 완료로 표시하지 않는다.

## 사용 서비스와 주요 프롬프트

사용 서비스는 OpenAI Codex다. 아래는 이번 대화에서 사용한 주요 요청이며 인증키가 포함된 메시지는 기록에 옮기지 않았다.

- “너가 공공데이터 포탈 들어가서 쓸만한거 찾아줘봐 탄소절감, 교통약자, 등등 주제 사이트에서 다시보고 쓸만한 데이터부터 이것저것 다 가져와서 얘기해보자” — 공개 자료와 주제 실행 가능성 조사.
- “얻을수있는 데이터에서 다른팀이 하지않을거같은 생소한 문제점 찾아줘봐” — 자료 기반 연구 질문 탐색.
- “쭉가보자 계획 짠거 확인하면서 진행해줘 앞으로 진행해야될거 체크리스트 만들어서 쭉해줘” — 실제 진행 상태 대조, 운행기록 집계·품질검사·그림과 재현 절차 작성.

이번 실행에서는 정류장·차량 배차 이력의 규칙성 점검, 정류장 연결과 가상 지점·중복 제외, 시설 목록 품질 확인, 공모전 HWP 양식의 필수 항목 추출에도 사용했다. AI가 만들어 낸 시설 좌표나 연료 분류를 원자료로 채우지 않았다. 코드의 자동 검사와 팀원의 최종 원문·결과 검토는 별개의 절차다.

거리 누적값과 운행기록의 연결 검사, 정류장 좌표를 이용한 거리 규모 검증, 별도 카카오 키를 사용하는 시설 주소 검색 코드·단위 테스트 작성에도 사용했다. 실제 지오코딩 응답과 건물 위치는 아직 확인하지 않았다.

시설 주소 문자열 대조와 후보 좌표의 300/500/800m 직선거리 진단, 시설코드별 중복 제거 코드에도 사용했다. 도로명만 있는 응답 2곳을 거리 진단에서 제외했으며, 문자열 일치를 건물 위치의 검수 완료로 표시하지 않았다.

미검색 주소는 도로명·건물번호를 보존하고 상세 표기만 분리하는 재조회 코드를 작성했다. 19곳 중 14곳에서 후보가 추가됐으며 원본 주소·시설코드·순서를 보존했는지 대조했다. 상세 표기 삭제로 단지 내 건물 식별이 약해질 수 있다는 한계를 기록했다.

시설 주변의 고유 노선과 노선 전체 운행기록 구성을 연결하고 미분류 상·하한, 30/50/80% 탐색 기준과 반경 민감도를 계산하는 데 사용했다. 정류장별 실측 도착비율로 해석하지 않았다. 도봉구수어통역센터 사례의 주소 보조 근거와 시설 유형, 1119번 예외승인 제약을 대조했으며 실제 교체 우선순위로 확정하지 않았다.

시설 종류별 연결 분모와 기존 조건부 진단을 대조하고, 차량 연료 연결자료·실제 휠체어 이용 실적의 공개 경로를 재검색했다. 확보하지 못한 자료를 미공개로 단정하지 않았으며 담당기관 문의 문안을 초안으로 작성했다. 외부 발송은 하지 않았다.

강북장애인종합복지관의 본관 주소를 한국장애인개발원 안내와 대조하고, 원본에 함께 적힌 별관 주소를 대안적인 대표점으로 비교했다. 두 위치 후보의 반경 진단 변화는 민감도로 기록했으며 현장 접근성 검수나 시설 2곳으로 취급하지 않았다.
