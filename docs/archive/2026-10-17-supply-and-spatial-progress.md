# 운행기록 현황과 공간분석 준비

> 당시 검증 과정을 보관한 메모다. 현재 결과·범위는 [최종 분석 범위](../scope-decision.md)와 [후보 공동 선정](../candidate-facility-comparison.md)을 따른다. 아래의 진행 상태는 작성 당시 기준이다.

## 분석 범위와 운행기록

기존 후보 393개 중 마스터 ID와 노선명이 일치하고 유형이 간선·지선인 375개를 우선 집계했다. 순환·광역 15개, 마스터 미확인 2개, 명칭 불일치 1개는 제외했다. 특정 지역의 수치가 유리해지는 방향으로 고른 목록이 아니라 기존 후보의 검증 가능한 부분집합이다. 다만 후보가 이름 일치로 만들어진 한계는 그대로 남는다.

전체 291,637행 중 포함 범위의 운행통계는 112,864행이다. 날짜·노선·차량·운행순번·출발시각 후보키의 중복 및 식별값 누락으로 제외한 행은 각각 0행이다.

| 항목 | 기록 수 | 포함 기록 대비 |
|---|---:|---:|
| 현재 저상 분류 연결 | 55,989 | 49.6% |
| 현재 일반 분류 연결 | 15,449 | 13.7% |
| 미확인 | 41,426 | 36.7% |
| 합계 | 112,864 | 100.0% |

분류 연결률은 63.3%다. 이 수는 앞서 전체 393개 후보의 차량·노선 조합 연결률 61.1%와 분모가 다르다. 동일 차량의 운행기록은 여러 행일 수 있다. 한 행의 완주 여부와 집계 의미가 완전히 확인되지 않았으므로 ‘운행 횟수’로 바꿔 부르지 않는다.

거리 양수는 111,900행, 0은 668행, 음수는 296행이다. 출발·최종 정류장 ID가 같은 기록은 1,132행이다. 이 항목들은 중복될 수 있다. 아직 거리값을 보정하거나 탄소계산에 사용하지 않았다. 0·음수값을 가진 행도 운행기록 분모에는 포함하고 품질 표시를 남겼다.

![운행기록 분류](../../outputs/public/figures/supply_record_composition.png)

현재 분류를 과거 운행일에 적용한다는 조건이 필요하다. 현 단계의 그림은 데이터 연결 범위와 유형별 구성을 보여주며, 실제 저상 도착 간격이나 노선별 수요 차이를 보여주지는 않는다.

## 배차 이력 검토

T-Data의 배차 정류장별 이력 73,451행과 차량운행별 이력 964행을 확보했다. 두 자료의 확인된 날짜는 10/13~15다. 날짜·노선·운행순번·계획 ID를 묶은 정류장 이력 그룹 958개가 모두 차량 이력의 키와 연결됐다. 정류장 이력에 나타난 노선은 155개, 차량 이력은 156개다. 전체 375개 분석 노선의 완전한 이력이 아니다.

정차시간은 72,493행에서 정확히 20초, 나머지 958행에서 0초였다. 순번이 인접한 도착시각 차이 72,493개는 모두 분 단위였고, 958개 그룹 중 928개에서 그룹 내부 간격이 일정했다. 순번상 다음 도착시각이 앞서는 경우도 14개 있었다.

이것만으로 계획표나 잘못된 자료로 확정하지 않는다. 다만 실제 관측과 계획·생성 시각의 구분이 확인되지 않아 저상 도착 간격과 승객 대기시간을 계산하지 않았다. 데이터명에 ‘이력’이 있다는 사실만으로 실측성을 보장하지 않는다. 필요한 문의 항목에 이 구분을 추가한다.

## 공간분석 입력

공식 정류장 파일 63,883행과 노선 경유노드 186,512행을 확보했다. 후보 375개에 속한 노드 82,647행을 정류장 ID와 대조했다. 경유노드는 정류장만으로 구성된 파일이 아니므로, 정류장 마스터에 없는 54,352행을 모두 데이터 손실로 해석하지 않는다.

가상 정류장과 중복 연결을 제외한 후 실제 위치 후보로 쓸 노선·정류장 연결은 27,823개, 정류장 ID는 7,922개다. 375개 노선 모두 적어도 하나의 정류장과 연결됐다. 좌표에는 한반도 주변의 넓은 범위 검사를 적용했으며, 서울 행정경계를 검증한 것은 아니다.

이 연결표는 같은 노선이 같은 정류장을 여러 번 방문해도 하나로 만든 생활권 분석 입력이다. 방향·회차 순서를 보존한 경로가 아니다. 방향별 경로 분석에는 원본 노드 순번과 회차 자료를 다시 사용해야 한다. 정류장 버퍼의 인구·시설을 단순 합산하지 않고 시설 ID 또는 공간의 합집합으로 중복을 제거해야 한다.

서울시 장애인지역사회재활시설 목록도 274행 확보했다. 고유 시설코드 274개, 25개 자치구이며 주소 결측은 없었다. 종류에는 복지관 58곳, 주간이용시설 144곳 등이 포함된다. 파일에는 좌표와 실제 이용자·통행량이 없다. 페이지의 데이터 갱신일은 2026-09-23이며 모든 시설의 조사일이 그날이라는 뜻으로 쓰지 않는다.

시설의 주소·좌표 출처·확인 상태를 채울 작업표를 `data/processed/facilities_geocoding_queue.csv`에 만들었다. 전화번호는 작업표에 옮기지 않았다. 시설 수는 잠재 목적지 분포를 설명하는 보조지표이며 휠체어 이용자 수나 실측 수요로 대체하지 않는다. 지오코딩 키가 없으므로 현재는 주소까지만 준비했다. 300/500/800m 생활권 결과는 아직 없다.

## 남은 핵심 입력

1. 연료와 거리 정의: 탄소 비교의 선행 조건이다. 지금까지 받은 마스터에는 차량 연료가 없다.
2. 시설 좌표와 검수: 주소→좌표 변환 뒤 시설 건물과 일치하는지 확인해야 한다. 동 중심점으로 대체하지 않는다.
3. 배차 이력의 실제시각 여부: 확인 전에는 공급 구성 분석 범위를 유지한다.
4. 예외·충전·차량규격: 연결 가능한 사례를 찾아 교체 가능성과 자료상 부족을 구분한다.

따라서 현재 완료된 결과는 원자료 검증, 조건부 저상 구성, 운행기록 구성과 공간분석 입력 준비다. 교통약자 수요와의 격차, 탄소감축량, 최종 전환 우선순위는 미완료다.
