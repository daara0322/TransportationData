# 검증 기록 보관

이 폴더는 2026-10-17~19 데이터 연결·품질 점검 과정의 근거를 보관한다. 문서의 ‘현재’, ‘아직’, ‘후속’은 작성 당시 상태다. 새 작업 목록이나 최종 결론으로 해석하지 않는다.

- 최신 결론: [후보 공동 선정](../candidate-facility-comparison.md)
- 분석 범위·한계: [범위 결정](../scope-decision.md)
- 실행 방법: [재현 순서](../reproduce.md)

과거의 미착수 계획을 요약한 자료 확보 검토·탄소 비교 준비 메모는 최종 문서와 중복돼 정리했다. 노선 연결, 운행기록, 거리·주소, 시설, 대표 위치 검증의 근거는 남겼다.
