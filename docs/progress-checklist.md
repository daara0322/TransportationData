## 판단 기록

- 현재까지 확인한 것은 차량 구성 차이다. 교통약자 수요나 실제 대기시간 격차를 검증한 상태는 아니다.
- 지역 코드 523만으로 서울을 필터링하지 않는다. 후보 목록·노선 유형·불일치를 함께 사용한다.
- 연구를 진행하면서 추가한 가정과 제외 기준은 결과가 유리해지는 방향으로 사후 변경하지 않고 문서에 남긴다.
- 이번 현황의 포함 기준: 후보 목록 가운데 마스터 ID·이름이 일치하고 노선유형이 간선(3)·지선(4)인 375개. 순환·광역 15개, 마스터 미확인 2개, 명칭 불일치 1개는 제외했다. 서울 전체 모집단으로 일반화하지 않는다.
- 정류장 이력의 규칙성이 높다는 사실만으로 가짜 자료나 계획표로 확정하지 않는다. 실제 관측이라는 확인 없이 대기시간 성과를 계산하지 않기로 했다. 이 판단의 비용은 도착 간격 분석이 늦어지는 것이다.
- 연료·거리 정의·시설 좌표가 아직 없으므로 전환안 효과 비교는 미완료다. 형식만 갖춘 가상 감축 결과로 체크리스트를 채우지 않는다.

## 2026-10-18 정리 기록

- 중간 확인용 HTML 18개를 삭제했다. 당시 집계값 대조에 사용한 서울시 버스 현황 페이지 1개만 보존했다. 분석 CSV·엑셀·API 응답은 삭제하지 않았다.
