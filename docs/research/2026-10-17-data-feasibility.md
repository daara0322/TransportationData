# 데이터 확보와 1차 검토

## 현재 판단

운행거리 자료는 원본을 확보했다. 저상 여부는 실제 API 응답을 받아 과거 차량·노선 조합 일부와 연결했다. 후보 393개 노선의 7,251개 조합 가운데 4,431개를 분류했다(61.1%). 상세 결과와 표본 한계는 `2026-10-17-lowfloor-linkage.md`를 참고한다. 차량별 연료구성은 아직 확보하지 못했다. 따라서 연구 질문은 유지하지만 차량 교체 후보와 최종 탄소·접근성 비교는 미착수 상태다.

## 운행통계에서 확인한 사실

- 파일 크기: 113,208,259 bytes.
- 행·열: 291,637행, 42열.
- 기준일별 행: 20261013 97,173 / 20261014 97,243 / 20261015 97,221.
- 고유 버스 ID 15,205개, 고유 노선 ID 1,334개. 이 수는 서울시 차량·노선 수가 아니다.
- 차량번호 접두어에 서울·경기·인천 등이 섞여 있다. 번호판 접두어만으로 최종 관할을 확정하지 않고 노선 마스터와 연결해야 한다.
- 거리 양수 246,779행, 0 41,933행, 음수 2,925행. 이 단계에서는 삭제하지 않았다.
- 날짜·노선ID·버스ID·운행순번·출발시각을 묶은 후보키의 중복은 0행. 후보키가 실제 운행 고유키임이 확정된 것은 아니다.
- 일부 차량번호가 짧게 제공돼 차량번호를 외부 자료의 확정 연결키로 사용하지 않는다.
- 거리 단위는 공식 정의 또는 실제 구간 대조를 통해 확인해야 한다. 현재 합계는 km로 환산하지 않았다.

3일 표본은 장기 평균·연간 실적을 대표하지 않는다. 계절·평일/휴일을 고려하지 않은 연간 환산을 하지 않는다.

## 인가현황 엑셀

한 시트 504행(헤더 포함), 15열이다. 업체명, 노선번호, 유형, 기종점, 인가/운행/예비대수, 인가거리, 운행시간, 횟수, 배차와 첫·막차 항목이 있다. 연료·저상 여부·노선 ID는 없다. 같은 노선에 여러 업체가 있으므로 행 수를 노선 수로 쓰지 않는다. 2026년 1월 자료와 10월 운행통계의 노선 변경도 확인해야 한다.

## 예외노선표에서 얻은 정책 단서

이미지 표기상 25개 노선, 15개사, 235대다. 교량마찰·급경사·도로폭 외에 전기충전시설 미설치와 중형버스 모델 단종이 사유로 적혀 있다. 개선계획에는 충전시설 설치와 노선 변경 등을 통한 대형 CNG 저상버스 도입이 제시된다. 동일 노선의 여러 업체와 사유 중복을 주의한다.

이 자료는 ‘교통약자 수요가 높다’는 이유만으로 즉시 전기저상버스 교체를 권고하면 안 된다는 근거다. 충전과 차량규격을 별도 제약으로 검토한다. 이미지의 숫자는 육안 확인이며 아직 구조화·집계 검증은 하지 않았다.

## 다음에 필요한 입력

1. 서울 버스위치 API의 다른 시간대 응답과 분류 시점 검증. 1차 수집은 완료했으며 미분류를 줄일 필요가 있다. https://www.data.go.kr/data/15000332/openapi.do
2. 분석 기준일과 일치하는 차량/노선별 연료·동력원 구성. 공개 자료에서 아직 확보하지 못했으며 미공개라고 확정한 것은 아니다.
3. 서울 관할 노선 마스터와 정류장 경로. 노선번호 문자열만으로 경기 노선과 결합하지 않는다.
4. 비교기간 확대용 운행자료와 거리 단위 설명.

API 키는 채팅이나 GitHub에 공개하지 않고 로컬 환경변수로 관리한다. 공개 CSV 다운로드에는 T-Data 키가 필요하지 않았으므로 T-Data 계정 신청을 현재 필수 작업으로 요구하지 않는다.
