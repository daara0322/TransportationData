# 거리 참조값 대조와 시설 좌표 준비

2026-10-18 기준. 분석 대상 375개 후보 노선, 운행기록 112,864행을 사용했다.

## 거리 검증에서 확인한 것

운행기록의 출발·최종 정류장 ID와 순번을 노선 노드의 ID·노드순번에 함께 연결했다. 정류장순번과 노드순번을 같은 값으로 취급하지 않았다. 양 끝의 누적거리 차이와 보고된 운행거리를 비교했으며 원본 값을 수정하지 않았다.

- 104,133행에서 양 끝 참조값이 유일하게 연결됐다. 나머지 8,731행은 참조값이 부족했다.
- 연결된 기록 중 81,839행은 거리 차이가 원자료 단위로 1 이하였다. 연결된 기록의 약 78.6%다.
- 보고 거리에서 참조 거리 차이를 뺀 값의 중앙값은 0, 10백분위는 -1, 90백분위는 3이었다.
- 양수 거리 111,900행, 0인 거리 668행, 음수 거리 296행이다. 0인 기록 중 646행은 양 끝 정류장 ID도 같았다.
- 음수 기록 가운데 참조 누적거리가 감소한 사례는 없었다. 음수를 회차나 순번 역전 때문이라고 단정하거나 절댓값으로 바꾸지 않는다.

좌표가 연결된 정류장을 노드순으로 나열해 연속한 두 지점 사이의 직선거리를 계산했다. 그 사이에 좌표가 없는 노드가 있을 수 있다. 양의 누적거리 차이 / 직선거리(m)를 구한 27,920개 구간의 중앙값은 1.020, 10백분위는 0.999, 90백분위는 1.398이었다. 거리의 규모가 미터와 가깝다는 근거다. 도로 굴곡과 현재 참조자료·과거 운행일의 차이가 있으므로 공식 단위와 한 행의 집계 범위가 확인됐다고 표시하지 않는다.

집계 결과: `outputs/public/distance_reference_audit.json`. 개별 차량·운전자 식별자는 공개하지 않는다.

## 시설 좌표 변환

공식 시설 목록 274곳의 주소를 카카오 주소 검색 API에 보내는 수집 코드를 준비했다. 별도 REST API 키가 없어 실제 요청은 아직 하지 않았다. 버스 API 키를 재사용하지 않는다.

[공식 주소 검색 문서](https://developers.kakao.com/docs/ko/local/dev-guide#address-coord)를 따라 발급한 REST API 키를 로컬 `.env`의 `KAKAO_REST_API_KEY`에 넣는다. 키를 채팅이나 GitHub에 올리지 않는다.

먼저 5건만 요청한다.

```powershell
python -m src.geocode_facilities --output data/processed/facility_geocode_candidates_trial.csv --limit 5
```

응답은 주소별로 캐시한다. 결과가 여러 개이거나 자치구가 다르거나 좌표가 유효하지 않으면 검토 상태로 남긴다. 유일한 주소 후보도 `candidate_unreviewed`이며 건물 위치 확인 전에는 분석에 사용하지 않는다. 기존 출력 파일은 수동 검수를 보호하기 위해 덮어쓰지 않는다. 시험 결과를 검수한 뒤 다른 출력 이름과 더 큰 요청 한도로 나머지를 수집한다. 캐시·주소별 결과는 Git 제외 대상이다.

## 다음 순서

1. 별도 키로 소규모 좌표 수집 후 실제 건물 위치를 검수한다.
2. 검수된 시설과 정류장 생활권을 연결하고 300/500/800m에 따른 차이를 비교한다. 시설 수는 실제 통행 수요와 구분한다.
3. 연료 자료·공식 거리 정의·현재 저상 분류의 과거 유효성을 확인한 다음 탄소 전환안을 계산한다.

## 실제 연결 시험

2026-10-18 별도 키를 로컬에 설정하고 공식 API 연결을 시험했다. 네트워크 접근이 가능한 실행에서 시설 주소 5건 모두 HTTP 오류였으며 좌표는 확보하지 못했다. 추가 진단 응답은 HTTP 403, `NotAuthorizedError`, `disabled OPEN_MAP_AND_LOCAL service`였다. 인증정보는 기록하지 않았다.

앱 관리 화면에서 TransportationData의 카카오맵 사용 설정을 ON으로 바꾼 뒤 재시험해야 한다. 무료 적용 앱 여부도 앱 화면에서 확인한다. 실패 기록을 성공한 수집으로 표시하지 않는다. 기존 실패 결과를 보존하려면 새 출력 이름을 사용한다.

```powershell
python -m src.geocode_facilities --output data/processed/facility_geocode_candidates_enabled.csv --limit 5
```

## 기존 앱으로 전체 수집 완료

2026-10-18 사용자가 지정한 기존 앱의 인증정보로 로컬 설정을 바꿔 5건 시험 후 전체 274곳을 조회했다. 인증정보는 Git에 포함하지 않는다. 좌표 후보 233곳, 검색 결과 없음 37곳, 서울 여부 확인 필요 2곳, 복수 후보 2곳이다. 건물 위치 검수 완료는 0곳으로, 확정적인 생활권·접근성 분석에 아직 사용하지 않는다. 실패·미확인 시설을 분모에서 제외하지 않는다.

집계는 `outputs/public/facility_geocoding_audit.json`, 주소별 결과는 Git 제외 대상인 `data/processed/facility_geocode_candidates_full.csv`에 있다. 다음은 후보 주소와 실제 건물의 대조 및 미검색 주소의 원문 확인이다.
