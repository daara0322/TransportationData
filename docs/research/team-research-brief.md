# 1인 진행 기준 (2026-10-20)

기관 문의·현장 확인·발표와 제출은 참가자 본인이 맡는다. 분석·코드·문서 정리는 현재 대화에서 지원한다. 아래 기존 조사 항목의 역할을 1인 기준으로 갱신했다. 파일명은 기존 링크를 유지하기 위해 보존했다.

# 정책·현장 조사 메모

지금 조사할 질문은 ‘전기저상버스 도입이 필요한데 실제로 어려운 조건이 무엇인가’다.

- 서울시 저상버스 예외승인표에서 충전·차량규격·도로 제약을 구분한다.
- 차량 교체 대상이 정해지는 기준, 충전시설 지원, 중형 저상차량의 운행 조건을 공식 자료로 찾는다.
- 자료마다 제목·기관·작성일·주소·근거 문장을 남긴다. 보도자료의 계획과 실제 도입 실적을 구분한다.
- 당사자 인터뷰가 가능하면 최근 이용 경험과 저상차량이 와도 타지 못한 이유를 묻는다. 일반인의 찬반 설문으로 정책효과를 검증하지 않는다.
- 참여 목적·보고서 활용 범위를 알리고 동의를 얻는다. 이름·연락처·상세 장애정보를 조사표에 넣지 않는다.
- 분석자가 만든 후보 노선이 나오기 전에는 특정 지역이 불리하다고 결론 내리지 않는다.

기관에 자료 요청이 필요하면 아래 내용을 사용해 문의 문안을 준비한다. 발송은 본인이 결정한다.

> 공개 운행자료를 활용한 연구를 위해 기준일별 버스 ID 또는 노선 ID에 연결 가능한 연료/동력원·저상 여부 현황을 찾고 있습니다. 개인·운전자 정보는 필요하지 않습니다. 공개 다운로드 위치 또는 이용 가능한 집계자료와 기준시점을 안내받을 수 있을까요?

## 10/17 데이터 대조 후 문의할 내용

본인이 확인할 우선순위는 설문보다 아래 자료 확인이다. 먼저 공개된 문서·명세에서 찾고, 답이 없으면 기관에 문의할 수 있다. 이 프로젝트에서 문의를 대신 발송하지 않았다.

1. **연료 연결자료:** 2026-10-13~17 기준 서울 시내버스의 차량 ID(vehId) 또는 노선 ID(routeId)와 연결 가능한 CNG·전기·수소 구성표가 있는지. 차량별 자료가 어렵다면 노선별 연료별 대수와 기준일을 요청한다. 번호판·운전자 정보는 필요 없다. 2023년 회사별 연료 통계는 이번 시점의 차량별 구성으로 사용할 수 없다.
2. **운행거리 정의:** T-Data 차량 운행통계(BisTbisStVehOprat)의 opratDstnc 단위, 한 행의 집계 범위, 0·음수값의 의미, 운행 중단·통신 누락 시 처리 규칙. 화면 다운로드 파일 ID 10277, 확인한 기준일은 20261013~15다. 담당 부서·연락처는 최신 [공식 명세](https://t-data.seoul.go.kr/dataprovide/trafficdataviewopenapi.do?data_id=1084)를 확인한다.
3. **후보 현실성:** 100·104·172번은 구성 차이를 설명하기 위한 사례다. 기존 예외승인 여부와 도로·차량 규격·충전 조건을 조사하되 우선 교체 노선으로 확정하지 않는다.
4. **배차 이력 시각:** 배차 정류장별 이력과 차량운행별 이력의 도착·출발 시각이 실제 관측인지 계획·생성 시각인지, 실제 저상 도착 간격을 산출하려면 어떤 테이블이 필요한지 확인한다. 제공 파일의 정차시간이 대부분 20초이고 동일 운행 그룹의 인접 시각이 일정해 해석 확인이 필요하다.

시설 주소의 좌표 변환은 [카카오 주소 검색 공식 안내](https://developers.kakao.com/docs/ko/local/dev-guide#address-coord) 등을 참고할 수 있다. 주소와 반환된 건물 위치를 검수해야 한다. 카카오 방식을 사용한다면 REST API 키가 필요하며, 발급 후 로컬 `.env`에 보관하고 Git에는 넣지 않는다. 2026-10-18 로컬 키로 후보 247곳을 확보했다. 실제 건물·출입구 검수는 미완료다. 미검색·불완전·표기 대조가 필요한 우선 확인 37곳은 `data/processed/facility_priority_review_refined.csv`에 있다. 주변 노선의 기록 구성 연결은 `2026-10-18-facility-supply.md`에 정리했다. 수어센터 등 시설 유형만으로 휠체어 수요를 가정하지 말고 이용자의 실제 이동 특성과 범위 밖 교통 대안을 확인해야 한다.

답변을 받으면 기관·답변일·기준일·원문과 해석을 나눠 기록한다. 구두 답변은 보고서에서 검증된 공개 통계로 표현하지 않는다.

## 10/18 분석 후 본인이 확인할 항목

기관 문의는 `../requests/bus-data-questions.md`의 문안을 사용한다. 이 문서는 발송 기록이 아니다. 자료를 받으면 기준일과 연결 단위를 먼저 적는다. 노선별 연료 대수만으로 차량별 실제 운행거리를 연료별로 배분할 수는 없다.

시설 확인은 수어센터·주간이용시설·복지관을 한 종류의 이용자로 가정하지 않는 데 목적이 있다. 공개 운영 안내나 기관의 집계 설명에서 확인 가능한 범위로 아래를 살핀다.

- 실제 주 출입구와 이용하는 건물은 어디인가? 본관·별관·아파트 동이 나뉘는가?
- 이용자의 이동은 어느 목적지·방향과 연결되는가? 근처 버스가 그 방향을 제공하는가?
- 기관의 송영차량이나 다른 이동 지원이 있는가? 단순 정류장 유무만으로 버스 의존을 가정하지 않는다.
- 휠체어 이용과 버스 이용의 관련성을 설명할 기존 공개 집계가 있는가? 없다면 이용자 수를 추정하지 않고 미확인으로 남긴다.

이름·연락처·개별 장애 진단·개인별 이동 기록을 수집하는 설문을 새로 만들지 않았다. 현장 의견을 듣는다면 참여 목적과 보고서 활용 범위를 먼저 설명하고, 사실 확인과 개인 의견을 나눠 적는다. 담당기관에 질문할 참가자는 본인 1명으로 변경됨이며 아직 기관 답변을 받은 상태가 아니다.
