# 최종 분석 범위 결정

2026-10-20 사용자 요청: “확보하지말고 진행하자”. 추가 데이터 수집·기관 문의·회신 대기를 완료 조건으로 두지 않는다. 1인 개인 참가 기준을 유지한다.

주제: **서울 버스의 전기저상 전환 검토를 위한 저상차량 구성과 운영 제약 분석**

## 포함

- 기존 375개 후보 노선의 운행기록과 현재 저상 분류를 조건부 연결하고, 미분류에 따른 구성 범위를 제시한다.
- 미분류를 양극단으로 놓아도 범위가 겹치지 않는 사례를 설명한다. 차량 대수와 운행기록의 분모를 구분한다.
- 시설 주변의 선정 노선과 다른 대안 확인 필요성을 정리한다. 시설 종류를 휠체어 수요로 추정하지 않는다.
- 공식 예외승인표의 도로·충전·차량규격 제약을 대조한다. 목록의 존재나 부재를 현재 가능·불가능 판정으로 단정하지 않는다.
- 약 42m 대표점 차이로 300m 진단이 바뀐 사례를 통해 위치·반경 민감도를 제시한다.

## 제외

실제 탄소감축량, 연료별 운행거리 배분, 동일 K의 교체 최적화·최종 우선순위, 실제 저상 도착 간격·대기시간, 수혜 인원·휠체어 통행 수요, 현장 접근성 개선 효과. 탄소중립과의 연결은 전기저상 전환이라는 정책 대상에 있으며 감축효과를 입증했다고 쓰지 않는다.

## 남은 제출 작업

현재 결과의 해석·문구 최종 확인, 이름·실제 참여 동기·신청서·동의·서명, 심사자 코드 접근 방법 결정과 재현 안내다. 기존 원자료와 당시 스냅샷을 이용한 내부 재실행 검증을 제3자의 원본 재확보 검증으로 표현하지 않는다.

기존 탄소 시나리오 계획과 문의 문서는 과거 검토 기록으로 보존한다. 현재 실행 기준은 이 문서다. 추후 원래 탄소 분석을 다시 하려면 별도 결정이 필요하다.
