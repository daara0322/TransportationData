## 붙임1 참가신청서

개인/팀, 신청자명(팀일 경우 팀명), 대표·팀원 이름·소속·이메일·연락처가 필요하다. 현재는 1인 개인 참가로 진행한다. 지원형태는 개인을 선택하고 신청자명과 본인의 이름·소속·이메일·연락처를 작성한다. 팀원 칸은 임의 정보를 채우지 않고 원본 양식에 따라 공란 또는 해당 없음으로 처리한다. 동의·서약과 본인 서명은 직접 원문을 읽고 작성해야 한다. 이 프로젝트에 이름·연락처를 임의로 채운 신청서나 서명 이미지는 만들지 않았다.

## 실질적으로 남은 핵심

1. 차량·노선의 기존 동력원과 거리 단위·집계 범위를 확인해야 탄소 전환안을 계산할 수 있다. 기관 문의 초안은 `requests/bus-data-questions.md`에 있다. 아직 발송·회신 기록은 없다.
2. 시설 출입구·실제 이동 특성·노선 방향을 확인해야 접근성 개선을 정책 효과로 해석할 수 있다. 약 42m 대표점 차이에 민감한 사례는 확정 취약지로 쓰지 않는다.
3. 현재 결과만으로 어떤 주장을 할지 본인이 확정해야 한다. 형식상 본문이 5쪽이어도 원래 탄소 비교를 완료한 보고서는 아니다.
4. 원본 재확보·당시 API 스냅샷·실행 환경과 코드 접근을 제3자가 재현할 수 있는지 점검해야 한다. 현재는 보관한 입력을 이용한 내부 재실행을 확인한 수준이다.

공고상 마감은 10/22이며 확인한 공고 본문에는 별도 마감 시각이 없었다. 23:59를 가정하지 않고 10/21 제출 목표를 유지한다. 실제 제출 이메일은 최종 공고와 다시 대조한다. 메일을 보내거나 저장소를 공개 전환하지 않았다.
