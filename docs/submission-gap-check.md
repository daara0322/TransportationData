## 붙임1 참가신청서

개인/팀, 신청자명(팀일 경우 팀명), 대표·팀원 이름·소속·이메일·연락처가 필요하다. 현재는 1인 개인 참가로 진행한다. 지원형태는 개인을 선택하고 신청자명과 본인의 이름·소속·이메일·연락처를 작성한다. 팀원 칸은 임의 정보를 채우지 않고 원본 양식에 따라 공란 또는 해당 없음으로 처리한다. 동의·서약과 본인 서명은 직접 원문을 읽고 작성해야 한다. 이 프로젝트에 이름·연락처를 임의로 채운 신청서나 서명 이미지는 만들지 않았다.

## 실질적으로 남은 제출 작업

1. 확정 주제는 ‘서울 버스의 전기저상 전환 검토를 위한 저상차량 구성과 운영 제약 분석’이다. 추가 자료 확보와 기관 회신을 기다리지 않는다. 탄소감축량·최적 교체 순위·실제 수요와 대기시간 효과는 범위에서 제외했다. `scope-decision.md` 참고.
2. 이름·소속·실제 참여 동기와 신청서의 본인 정보·동의·서명을 작성한다. 문서에 개인 정보를 임의로 채우지 않았다.
3. 구성 범위·시설 대안·공식 제약·위치 민감도라는 결론이 원자료와 일치하는지 본인이 최종 검토한다. 출입구 미검수 등의 한계는 남긴다.
4. 공개 코드 접근은 확인했다. 원자료 확보·당시 스냅샷·실행 환경 안내의 한계를 확인한다. 현재는 보관한 입력의 내부 재실행을 확인한 수준이다.

공고상 마감은 10/22이며 확인한 공고 본문에는 별도 마감 시각이 없었다. 23:59를 가정하지 않고 10/21 제출 목표를 유지한다. 실제 제출 이메일은 최종 공고와 다시 대조한다. 메일은 보내지 않았다. 이후 10/20 사용자 승인으로 저장소 공개 전환과 로그인 없는 접근을 확인했다.
