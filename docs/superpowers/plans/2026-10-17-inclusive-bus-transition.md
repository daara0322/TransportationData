# 탄소저감과 교통약자 접근성을 함께 고려한 버스 전환 우선순위 분석

작성일: 2026-10-17
상태: 주제 설계 및 데이터 검증 계획. 분석 결과와 최종 대상지역은 아직 확정하지 않음.

진행 기록(2026-10-17): 차량 운행통계 CSV(291,637행, 10/13~15), 1월 인가현황과 예외노선표 원본을 확보했다. 실시간 API의 현재 저상 분류를 후보 노선의 과거 차량·노선 조합 중 61.1%에 연결했다. 공식 노선 마스터와 차량별운행노선정보도 확보해 미일치와 조건부 구성 범위를 기록했다. 거리 단위·차량별 연료·분류 시점 검증이 남아 있어 탄소 및 교체 순위는 미산출 상태다. 상세 기록: `../../research/2026-10-17-data-feasibility.md`, `../../research/2026-10-17-route-master-validation.md`.

## 1. 주제와 질문

주제명: 탄소저감과 교통약자 접근성을 함께 고려한 버스 전환 우선순위 분석 — 서울 버스노선을 대상으로

핵심 질문: 한정된 차량 교체 자원을 어디에 먼저 투입해야 운행 탄소배출을 줄이면서 저상버스 이용 기회의 격차도 개선할 수 있는가?

기존 전환정책이 불공정하다는 결론을 전제하지 않는다. 현황에서 격차가 있는지 확인하고, 같은 자원 조건의 전환안을 비교한다. 실제 정책의 차량별 선정 기준을 확보하지 못하면 분석의 탄소 중심 비교안을 ‘현행 정책’이라고 부르지 않는다.

대상 교통약자는 우선 저상차량이 필요한 이동약자다. 휠체어 이용자를 중심 사례로 설명하되, 장애유형만으로 휠체어 사용 여부를 판단하지 않는다. 고령인구는 별도의 보조 분석에 사용하며 모든 고령자를 저상버스 필수 이용자로 간주하지 않는다.

## 2. 분석 범위

서울을 1차 조사 대상으로 삼는다. 시내·마을·광역 등 노선유형은 분리하고, 운행 조건이 비교 가능한 유형부터 분석한다. 전기차 보급률이 낮거나 비저상차량이 존재할 것으로 예상된다는 이유만으로 특정 유형을 최종 대상으로 정하지 않는다.

주 분석은 기존 내연기관 차량을 전기저상버스로 교체하는 시나리오다. 차량 배정, 운행량, 차고지 충전 등 운영조건이 유지되거나 명시적으로 반영된 경우만 비교한다. 수소버스·노선 신설·특별교통수단 대체는 초기 범위에서 제외한다.

현재 접근성의 제약과 교체로 달라지는 접근성을 구분한다. 이미 저상인 CNG버스의 전기버스 교체는 탄소효과가 있을 수 있어도 저상 운행 증가로 계산하지 않는다. 저상 여부만으로 실제 탑승 가능성 전체를 판정하지 않는다.

## 4. 데이터 검증 후 진행 판단 — 10/17

- [ ] 차량 분류, 운행통계, 노선 자료를 소규모로 확보한다.
- [ ] 노선 ID·차량 ID 연결과 분류 기준시점을 확인한다.
- [ ] 운행거리 단위·왕복/회차·중복기록을 검증한다.
- [ ] 교체 대상 비저상 내연기관 차량과 운영 가능한 후보 노선이 실제 존재하는지 확인한다.
- [ ] 분석기간과 노선유형을 확정하고 원본 모집단 대비 포함·제외 범위를 기록한다.

진행 조건: 연료·저상·운행량을 일관된 단위로 연결할 수 있고, 접근성 효과가 생기는 교체 후보가 존재한다.

범위 조정 조건: 차량 단위 자료가 없고 노선별 구성만 있으면 노선 단위 시나리오로 한정한다. 시간별 이력이 없으면 보급·공급 격차까지만 분석하고 대기시간 개선을 주장하지 않는다.

중단 조건: 연료구성이나 운행량을 뒷받침할 자료가 없거나 비저상 교체 후보가 없으면 이 도시·유형에서 주력 주제를 확정하지 않는다. 서울 총량을 노선에 비례 배분해 핵심 결과를 만들지 않는다.

- [ ] 저상 서비스가 적으면서 관련 수요지표가 높은 생활권이 있는지 확인한다.

- [ ] 예외승인 노선과 정류장 접근 조건을 확인해 즉시 교체 대상과 별도 개선 필요 대상을 나눈다.

핵심 결과물: 차량 구성표, 수요·서비스 격차 지도, 후보 노선 목록과 선정 근거.

## 6. 전환안 비교 — 10/19~20

기본 비교는 동일 교체 대수 K를 사용한다. K는 확인한 후보 차량 수와 실제 계획자료를 보고 정하며, 가능한 경우 5/10/20대 등 여러 규모를 비교한다. 동일 대수는 동일 예산을 뜻하지 않는다. 비용·충전투자 자료가 있으면 총비용 제한 분석을 별도로 추가한다.

비교안 A: 추정 운행 탄소저감량이 큰 교체안.
비교안 B: 저상 서비스 개선이 큰 교체안.
비교안 C: 접근성의 최소 개선 조건을 달리하며 탄소저감량을 최대화하는 안.

단순 가중합 점수 하나로 최종 순위를 확정하지 않는다. 탄소와 접근성을 동시에 개선하는 후보와 두 목표 사이 선택이 필요한 후보를 보여준다. 충전·차량규격·운행가능성·차령 자료가 없으면 실제 교체확정 목록 대신 정책 검토 후보로 제안한다.

- [ ] 교체 대상의 기존 연료·저상 여부를 반영한다.
- [ ] 가능한 경우 차량별 운행 회차를 유지해 교체 후 저상 운행을 재계산한다.
- [ ] 시간자료가 없으면 저상 운행 추가량과 커버리지를 지표로 사용한다. 실제 추가 이용자 수로 표현하지 않는다.
- [ ] 수혜 인구 중복과 기존 저상노선의 대체 가능성을 반영한다.
- [ ] 충전으로 운행량·예비차 수가 달라지는 시나리오를 검토한다. ‘운행량 동일’은 가정으로 명시한다.
- [ ] 외곽·저수요 생활권의 개선과 소외 여부를 별도로 비교한다.
- [ ] 여러 K·접근성 조건·에너지계수에서 결과가 유지되는지 확인한다.

## 7. 탄소 계산

기본 산정경계는 운행 단계의 연료 연소와 전력 생산 배출이다. 배출계수의 상류범위가 다르면 그대로 비교하지 않는다. 차량·배터리 제조를 제외하면 전과정 탄소효과라고 부르지 않는다.

차량별 연간 운행거리 D(km), 기존 연료 사용원단위 f(연료단위/km), 연료 배출계수 c(kgCO2e/연료단위), 전비 e(kWh/km), 전력 배출계수 g(kgCO2e/kWh)일 때:

추정 운행 감축량 = D × (f × c − e × g)

충전 손실은 전비가 차량 소비 기준인지 충전 입력 기준인지에 따라 한 번만 반영한다. 자료의 표본 기간을 연간으로 확대할 때 평일·휴일·계절의 대표성을 확인하며, 대표성이 없으면 표본기간 효과만 제시한다. 음수 감축량도 숨기지 않는다.

저상버스 개선에 따른 승용차·택시 전환효과는 기본 감축량에 포함하지 않는다. 별도 수요 근거가 있을 때만 추가 시나리오로 계산한다.

## 8. AI의 역할과 검증

주력 결과는 현황 분석과 제약조건을 둔 정책 시나리오다. AI 사용을 위해 불필요한 예측모형을 붙이지 않는다. 자료 규모와 시간 변화가 충분하면 미래 운행량·수요 예측을 추가하되, 시간순 평가와 과거 평균 기준모형을 비교하고 순위가 얼마나 바뀌는지 확인한다. 최적화 알고리즘을 사용했다는 이유만으로 AI라고 부르지 않는다.

생성형 AI를 자료 정리·코드·문장 검토에 사용한 내역은 실제 작업과 검증 방법대로 기록한다. 공고 및 첨부양식의 AI 활용 작성 항목을 확인한다. 어떤 경우에도 모형 성능과 개선 효과를 선작성하지 않는다.

자연스럽고 구체적으로 쓴다. ‘친환경 전환이 교통약자를 소외시켰다’는 인과 주장을 먼저 정하지 않는다. 관측된 공급 격차와 계산한 전환효과를 구분한다. 예: ‘노선별 운행거리와 저상차량 구성을 연결하고, 같은 교체 대수에서 탄소와 접근성 지표가 어떻게 달라지는지 비교했다.’

## 11. 최종 판단 기준

데이터 연결이 성립하고, 비저상 내연기관 차량의 교체로 두 효과를 함께 평가할 수 있으면 이 주제를 확정한다. 다목적안이 더 낫다는 결과를 전제하지 않는다. 두 목표가 충돌하면 그 비용과 선택지를 보여주는 것도 결과다. 예외노선·충전제약이 핵심이면 차량 교체만으로 해결할 수 없는 생활권을 별도로 제안한다.
