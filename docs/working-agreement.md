# 1인 진행과 작업 비용 기준

2026-10-20 사용자 요청으로 1인 개인 참가로 전환했다. 과거 계획의 2인 역할 분담은 당시 기록이며 현재 역할에 적용하지 않는다.

- 본인: 기관 문의·현장 확인, 연구 범위와 결과 해석 결정, 이름·연락처·동의·서명, 발표·제출.
- 현재 대화: 확보된 자료로 분석·코드·문서 작성 지원. 새로운 사실이나 회신을 만들어 넣지 않음.
- 별도 검토 에이전트는 사용자가 요청하지 않는 한 추가로 띄우지 않음.
- 기존 결과·출처·검증을 재사용하고 변경된 부분만 읽고 수정함. 같은 검색과 전체 문서 재작성을 반복하지 않음.
- 문서·표현 변경에는 관련 내용·레이아웃만 확인. 분석 코드 변경 시 필요한 테스트를 실행하며, 새 실패나 영향 범위가 없으면 같은 전체 검사를 반복하지 않음.
- 작은 진행마다 파일·그림·커밋을 늘리지 않고 의미 있는 작업 단위로 정리함.
- 연료 자료·거리 정의·실제 수요가 없으면 탄소감축량과 최종 교체 순위를 임의로 계산하지 않음. 막힌 항목의 반복 검색 대신 자료 확인 또는 범위 결정을 요청함.

현재 우선순위는 새로운 분석 확장이 아니라 탄소 입력 확보 가능성 확인과 제출 범위 확정이다. 검토용 보고서는 최종 제출본과 구분한다.
